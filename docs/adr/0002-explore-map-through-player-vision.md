# 按玩家视野探索地图

首个联机里程碑公开整张棋盘。经典地图采用按玩家探索的布局。开局公开棋盘外框，完整地图留在服务端，由房间按玩家的当前视野揭示格子和格边。玩家靠探索发现路线，离开视野后仍能用地图记忆规划返程。

## 视野和地图记忆

- 玩家在无遮挡的棋盘内部能看见自己所在格和周围八格。墙和关闭的门遮挡视线，窗可以看穿。斜角沿用现有的两条正交路径遮挡规则。
- 相邻两格中有一格可见，就能发现它们共用的墙、门或窗。被挡住的另一格仍可能是未探索格。一条共享格边只绘制一次。
- 曾经看见的格和格边进入该玩家的地图记忆。离开视野后，门的记忆标记显示最后一次看到的状态。旧目击带回合和拍数。

## 画面和镜头

| 格子的状态 | 表现 |
| --- | --- |
| 当前可见 | 绘制完整场景、可见格边和局部光照，近景细节以暮林石室为基准。 |
| 已探索但不在当前视野 | 绘制简化灰色地图，保留已发现的布局和格边标记。 |
| 未探索 | 用同一色系的空灰格占位。已经发现的共享格边仍以标记显示。 |

默认镜头近看并跟随自己的棋子。「全图」显示棋盘外框和已发现的布局。旋转、平移和缩放只改变镜头取景。客户端只为当前可见格绘制精细场景和局部光照，其余格用平面表达。

## 对联机和回放的影响

玩家视图携带棋盘外框、当前观察和该玩家的地图记忆。尚未被该玩家发现的格子模板、布局和格边留在服务端。重连恢复该座位的探索记录，逐拍播放采用各拍已获准的视野与地图记忆。
